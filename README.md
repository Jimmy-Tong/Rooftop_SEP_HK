# Rooftop Solar Energy Potentials (SEP) in Hong Kong

This repository contains the code and associated datasets for the research article entitled *"Rooftop solar supports carbon-neutral transition in Hong Kong’s building sector"*.  

<br>

## **🖥️Machine Learning Model**:

The code to apply the pretrained machine learning model for global solar radiation (GSR) estimation and associated model inputs are available now.

- Pre-trained machine learning model for all-sky GSR estimation: [Model](Pretrained_Model.joblib)
- Python Code to apply the pretrained machine learning model: [Code](Apply_RF_Model.py)

<br>

## **📊Datasets**:

The sample datasets for the model inputs are available on Figshare at [Link](https://doi.org/10.6084/m9.figshare.33349182) 

- Sample datasets for the model inputs:
  - Daily clear-sky GSR: [Day one](https://figshare.com/account/articles/33349182?file=67953358), [Day two](https://figshare.com/account/articles/33349182?file=67953442)
  - Daily cloud optical thickness: [Day one](https://figshare.com/account/articles/33349182?file=67953598), [Day two](https://figshare.com/account/articles/33349182?file=67953613)
